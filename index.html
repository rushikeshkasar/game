How to Play

  1. 01

    Move the Snake

    Use arrow keys or WASD to move. On mobile devices, tap the on-screen arrow buttons below the board.

  2. 02

    Eat Apples to Grow

    Eat apples to grow longer. Each red apple adds 10 points to your score and gradually increases speed.

  3. 03

    Avoid Walls & Body

    In Solid Walls mode, hitting the border ends the game. In Wrap-Around mode, you pass through to the opposite edge.

  4. 04

    Beat Your Record

    Try to achieve the highest score and save your name to the local leaderboard after Game Over.

About

Snake Game is a classic arcade game developed using HTML, CSS, and JavaScript. This project demonstrates fundamental programming concepts including loops, conditions, event handling, arrays, collision detection, and DOM manipulation.

Loops & Game Tick · Arrays for Snake Segments · Collision Detection · DOM & Keyboard Events · Hash Multi-Page Routing · localStorage Persistence

Made as a college mini-project · Technology: HTML, CSS, JavaScript
